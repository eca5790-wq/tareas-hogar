# Pantalla · Inicio

## Objetivo

Mostrar en menos de 5 segundos:

-   Tareas de hoy.
-   Clasificación semanal.
-   Últimas tareas.
-   Tareas olvidadas.

## Componentes

-   Perfil activo.
-   Tarjeta "Hoy".
-   Tarjeta "Esta semana".
-   Tarjeta "Últimas tareas".
-   Tarjeta "Tareas olvidadas".
-   Barra de navegación inferior.

------------------------------------------------------------------------

# Pantalla · Registrar

## Objetivo

Registrar una tarea en 1-3 toques.

## Orden

1.  Buscador.
2.  Más habituales.
3.  Hoy.
4.  Categorías.

## Reglas

-   Más habituales = histórico conjunto de ambos usuarios.
-   Últimos 6 meses.
-   Máximo 5 tareas.
-   Excluye las tareas de "Hoy".

Tras registrar:

-   Confirmación.
-   Posibilidad de deshacer unos segundos.

------------------------------------------------------------------------

# Pantalla · Tareas

## Objetivo

Administrar las tareas.

Funciones

-   Crear.
-   Editar.
-   Desactivar.
-   Ver programación.

Cada tarea muestra:

-   Nombre.
-   Recurrencia.
-   Última realización.
-   Valor actual.

# Pantalla · Ajustes

Secciones

-   Perfil.
-   Categorías.
-   Configuración de puntos.
-   Exportación.
-   Información.

No incluye configuraciones innecesarias como temas o notificaciones.

# Componentes reutilizables

-   Tarjeta.
-   Buscador.
-   Lista de tareas.
-   Badge de puntos.
-   Badge "Hoy".
-   Confirmación.
-   Selector de perfil.
-   Barra de navegación.
-   Tarjetas de estadísticas.

------------------------------------------------------------------------

# Principios UX

-   Una funcionalidad = un único lugar.
-   Registrar debe ser la acción más rápida.
-   Mínimo número de pulsaciones.
-   Diseño limpio.
-   Material Design 3.
-   Optimizada para uso con una sola mano.
