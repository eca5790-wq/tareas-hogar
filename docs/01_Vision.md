# 01_Vision

# Tareas Hogar

## Objetivo

Aplicación web (PWA) para gestionar las tareas del hogar entre Elena y
Tomás.

## Usuarios

-   Elena
-   Tomás
-   Sin login.

## Objetivos

-   Registrar tareas en 1-3 toques.
-   Gestionar tareas recurrentes.
-   Reparto equilibrado.
-   Histórico.
-   Estadísticas.

## Tecnologías

-   React
-   Vite
-   Tailwind CSS
-   Google Apps Script
-   Google Sheets
