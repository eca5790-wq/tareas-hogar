# 07_API

**Versión:** 1.0

## Endpoints previstos

### GET /dashboard

Devuelve la información de Inicio.

### GET /today

Devuelve las tareas programadas para hoy.

### GET /tasks

Listado de tareas.

### GET /stats

Estadísticas.

### POST /register

Registra una tarea realizada.

### PUT /task

Actualiza una tarea.

### POST /task

Crea una tarea.

### DELETE /task

Elimina una tarea (solo sin histórico).
