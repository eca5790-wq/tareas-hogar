# 11_DesignSystem

**Versión:** 1.0

## Objetivo

Definir la identidad visual de la aplicación.

------------------------------------------------------------------------

# Filosofía

-   Minimalista.
-   Mucho espacio en blanco.
-   La información tiene prioridad sobre la decoración.
-   Optimizada para uso diario.

------------------------------------------------------------------------

# Paleta

  Variable           Color
  ------------------ ---------
  --background       #F7F8FA
  --surface          #FFFFFF
  --primary          #4F6D7A
  --text-primary     #1F2937
  --text-secondary   #6B7280
  --success          #22C55E
  --warning          #F59E0B
  --danger           #EF4444
  --border           #E5E7EB

------------------------------------------------------------------------

# Tipografía

Fuente: Inter

Pesos: - 700 Títulos - 600 Subtítulos - 400 Texto

------------------------------------------------------------------------

# Espaciado

Sistema de 8px.

Valores:

-   4
-   8
-   16
-   24
-   32

------------------------------------------------------------------------

# Tarjetas

-   Fondo blanco
-   Radio 16px
-   Padding 20px
-   Sombra suave

------------------------------------------------------------------------

# Botones

Primario: - Color principal - Texto blanco

Secundario: - Fondo blanco - Borde gris

------------------------------------------------------------------------

# Navegación

Cinco elementos:

-   Inicio
-   Tareas
-   Registrar
-   Estadísticas
-   Ajustes

------------------------------------------------------------------------

# Iconos

Material Symbols Rounded.

------------------------------------------------------------------------

# Gráficos

Permitidos:

-   Barras
-   Líneas
-   Indicadores

No utilizar gráficos de sectores.

------------------------------------------------------------------------

# Animaciones

200 ms

-   Cambio pantalla
-   Toast
-   Modal
-   Pulsación

------------------------------------------------------------------------

# Principios UX

1.  Una funcionalidad = un único lugar.
2.  Registrar debe ser la acción más rápida.
3.  Diseño consistente.
4.  La información prevalece sobre la decoración.
5.  Uso con una sola mano.
